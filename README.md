# The YouTube Engagement Chronicle 📊

An advanced, end-to-end Data Science capstone platform built to replace traditional content creation guesswork with real-world, evidence-based metrics data streams. This unified ecosystem automates the complete data pipeline—from live web extraction and API processing to natural language text classification, algorithmic tracking, and statistical significance testing.

## 🚀 Core Features & Advanced Data Pipelines
* **Live Public Stream Ingestion:** Replaces static or mock datasets by integrating live requests directly with the **YouTube Data API v3** to extract public video metadata, real-time engagement logs, and raw audience text comments.
* **Weighted Virality Scoring (Step 8):** Implements a structured mathematical matrix that prioritizes deep, high-intent user connections (**Shares and Saves**) over simple, passive engagement (**Likes**) to measure true community alignment.
* **NLP Sentiment Processing Engine (Step 9):** Leverages **TextBlob** natural language processing text analysis loops to automatically read human sentences row-by-row, calculating an objective text polarity index to tag comments as *Positive*, *Negative*, or *Relatable*.
* **Psychological Friction Flagging (Step 10):** Runs localized algorithmic string parsing arrays that automatically scan text rows for hidden friction keywords (*anxiety, stress, pressure*) to verify and quantify true audience problem awareness levels.
* **Rigorous A/B Testing Framework (Steps 11 & 12):** Employs **SciPy independent sample T-test modules** to mathematically evaluate differences across media formatting variations (Shortform Reels vs. Longform Videos), calculating definitive **P-values** to scientifically prove strategy significance.
* **Prescriptive Strategy Optimization (Step 13 & 14):** Automatically analyzes historical performance data to output clear content checklists mapping out optimal upcoming topics, hooks, and caption structures alongside rising external trend indices.
* **Management Frontend Deployment (Phase 5):** Packages the underlying data assets into a highly stylized, interactive graphic dashboard built using **Streamlit** to host responsive KPIs and charts for easy data discovery.

## 🛠️ The Technical Stack
* **Core Language & Processing:** Python 3.14 (Pandas, NumPy)
* **API Connection Routing:** Google API Client Discovery Libraries
* **Text Analysis & Language Modeling:** TextBlob NLP Module
* **Relational Database Management:** MySQL Server Instance & SQLAlchemy Engines
* **Statistical Modeling & Hypotheses:** SciPy Statistical Packages
* **Application Frontend Framework:** Streamlit Open-Source Server Layer

## 📈 Underlying Database Architecture
The analytical backend operates on a relational relational schema configured within **MySQL Workbench**, structured with strict cascading foreign key constraints (`ON DELETE CASCADE`):

1. **`content_performance` Table:** Stores video production attributes, title strings, structural hook tags, posting schedules, and raw engagement counts.
2. **`user_comments` Table:** Houses individual text rows, AI-calculated sentiment tags, binary problem awareness indicators, and dynamic automated collection timestamps.
